# 3D 辦公室自製素材包（11-08 使用者拍板：自己做一套，AI 用 Blender 建模）

目標：跟參考影片（IG「AI Agent Virtual Office」demo）並排看不輸。版權全部歸我們，不用外部素材包。
場景接線（格局、燈光、名牌、載入點）由 H5 負責；本文件只管素材本身。

## 做法

- **全部用 Blender 腳本產生**（Blender 5.1.2，`/Applications/Blender.app`），腳本放在 `tools/assets/`，一件一個函式，
  `blender --background --python tools/assets/build.py -- <名稱|all>` 可以重跑出同樣的結果。不手動修改 .blend 檔。
- 輸出：`windows/ShoWork.Win/Board/Web/assets/office/<名稱>.glb`（Mac、Windows 共用）。
- 驗收截圖：每件做轉台四視角截圖，並排成總覽表；用 Blender MCP 的 `look` 或無頭算圖產生，**使用者要放大看**。

## 風格規範

- 低多邊形、平面或柔和著色，比例寫實，人大約 7 頭身，不要做成方塊娃娃。參考 demo：人物有臉、眼鏡、髮型，衣服上有圖案。
- 單位：1 = 1 公尺。原點放在物件底面中心，glTF 的 +Y 朝上、正面朝 −Z。
- 面數上限：小物 ≤ 300 三角面、家具 ≤ 1,500、大件（撞球桌、中島）≤ 3,000、人物 ≤ 4,000（含頭髮）。
- 材質：**全部共用一張調色盤貼圖**（256×256 色塊，UV 對到色塊）⇒ 整個場景只有一個材質、一次 draw call。
  會發光的（螢幕、燈）另外用一張發光調色盤。色票定在 `tools/assets/palette.py`：暖木、深木、布紅、深灰、白、金屬、植物綠等。
- 細節靠形狀：倒角、隔板、把手、螢幕框、書背。不要用法線貼圖。

## 人物

- 基礎體兩種（體型 A／B），共用同一副骨架（骨頭名稱照 Mixamo 慣例，例如 `Hips`、`Spine`、`Head`、`LeftUpLeg`…）。
- 模組件：頭髮 6 種、上衣 4 種（T 恤可以印圖案、襯衫、西裝外套、帽 T）、褲子 2 種、配件（眼鏡、耳機、帽子）。
  網頁端依 AI 的名字組裝，固定組合，所以同一個 AI 每次長得都一樣。
- 動作（glTF animations）：`idle`、`walk`、`sit`、`type`（坐著打字）、`wave`、`think`（手托下巴）。
- 狀態色不要染在人身上：網頁端在腳下畫光圈，或在頭上放小圓點。

## 驗收

1. 每件的轉台截圖（使用者放大看）。
2. 組進場景以後：總覽、走進去（工作區／休息區／茶水間）各一張，跟參考影片對應的影格並排比較。
3. 效能：整個場景在 Mac mini M4 上 ≥ 50 fps（headless 量的 fps 不準，要用真視窗量）。

## Blender 腳本的坑（實測過的）

- `transform_apply` 只對**已選取**的物件有效，只設 active 會靜默失效：先 `select_all(DESELECT)` → `ob.select_set(True)` 再 apply。
- 5.x 的節點不能用名字取：用 `next(n for n in nodes if n.type == "BSDF_PRINCIPLED")`。
- 用了 `--factory-startup` 就絕對不要 `save_userpref()`，會把使用者偏好蓋掉。
- 浮點座標比對要留容差（`abs(a-b) < 1e-5`）。
