# ShoWork42 · 自動排版（2026-09-26 Keng 提出，與光暈同屬「多視窗工作管理」）

## 已拍板
- 排**所有**終端機視窗：Ghostty、Terminal.app、iTerm2 通用。
- 預設自動排（視窗數量變動就重排），選單列可以關掉；`⌃⌥L` 立即排版。
- 4 個視窗：「四等分直欄」和「2×2」兩種都要，按 `⌃⌥L` 切換。
- 排版由 ShoWork42 接手，ghosts 的自動搬視窗功能請 Keng 在 ghosts 關掉（不直接改 ghosts）。

## 規則（以主螢幕的可用區域為準，扣掉選單列和 Dock）

| 視窗數 | 排法 |
|---|---|
| 1 | 放到最大（不是原生全螢幕） |
| 2 | 左右各半，上下占滿 |
| 3 | 三等分直欄，上下占滿 |
| 4 | 四等分直欄 ⇄ 2×2（`⌃⌥L` 切換） |
| 5–8 | 上下兩排、不重疊、平均寬度（上排 ⌈n/2⌉ 個，下排 ⌊n/2⌋ 個） |
| 9–11 | Keng 現在的錯位疊法：每個約寬度的 1/4（≈60×40 字）；上排 4 個、中排 3 個（錯開半個寬）、下排 4 個；三排往下錯開，**每個標題列都露在外面** |
| 12+ | 多出來的沿中排往右下錯開 |

- 排列順序：依照視窗目前的位置（由上而下、由左而右），讓每個視窗盡量留在原本附近，不會大洗牌。
- 最小化、全螢幕、在別的桌面的視窗不列入。

## 驗收
1. 單元測試：每個數量 1–14 的框都在可用區域內；1–8 不重疊；9–11 每個標題列至少露出 28pt。
2. 實測：Ghostty／Terminal／iTerm2 混合開 1–11 個視窗，每個數量都排對（用系統視窗清單核對位置）。
3. 自動排：開一個、關一個都會重排；關掉「自動排版」後不再動。
4. 光暈跟著排版後的新位置走。
5. Keng 看過點頭。
